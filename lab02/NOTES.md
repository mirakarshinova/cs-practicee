Рабочая папка - все файлы, с которыми работаем
индекс - промежуточная область между рабочими файлами и коммитом, выбор того, что нужно сохранить дальше
коммит - фиксация всех изменений, сохраненное состояние проекта в гите
Гит - программа на компьютере с историей файлов и тд
ГитХаб - сайт, на который отправляются репозитории
Использованные команды: 
git status - показывает, что происходит сейчас в репозитории
git diff - что изменили в файлах, но не добавили в индекс
git diff --staged - какие изменения войдут в следующий коммит
Ветки:
ветка - отдельная линия версий проекта
при новом коммите указатель текущей ветки перемещается на новый коммит
слияние переносит изменения из одной ветки в другую
